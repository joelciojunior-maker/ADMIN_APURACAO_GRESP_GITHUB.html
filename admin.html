Senha local opcional

O painel começa sem senha. A senha local serve apenas para impedir abertura casual neste navegador. Como o site está no GitHub Pages, a senha local não substitui autenticação de servidor e pode ser contornada por alguém com conhecimento técnico. O token do GitHub continua sendo a proteção real contra publicação.

Preferências

O token nunca é gravado permanentemente. Se escolhido, o token permanece somente na aba atual.
